# video-downloader-updates

视频抓取下载器更新说明与 Windows x64 安装包。

## 最新版本：v4.8.10（2026-10-02）

相对 4.8.9，本次修复分享链接识别并加强下载去重：

- 精准获取接受包含视频链接的完整分享文案，自动提取有效 HTTP(S) 链接，修复抖音分享文案触发 `Failed to construct 'URL': Invalid URL`；识别后保存作品链接，重试及历史恢复共用同一后端入口。无链接或多链接输入会给出明确提示，多作品仍可用加号分别添加。
- 已知作品通过平台作品 ID 与持久化本地索引避免重复下载，跟踪参数、不同任务及重启不再创建新的作品身份；同一作品的并发下载共用去重检查。
- 文件哈希匹配前重新核验保留文件，避免已删除或被修改的旧文件阻止重新下载，或错误删除刚下载的文件。
- 新增后台多帧视觉查重，识别部分更换码率、分辨率或帧率的重复视频；仅在下载空闲时运行，新下载开始就暂停视觉检查，不让下载入口等待它。
- 表格、缩略图、精准获取和下载记录显示“疑似重复”及对应文件；视觉匹配只标记并保留文件，不自动删除。依赖许可证随运行组件一起打包。

验证范围：分享文案入口、链接保留、历史恢复、并发作品去重、哈希校验、真实本地生成视频的重编码匹配及空闲调度回归通过；前端界面流程使用模拟桌面接口验证。全量 Go 测试、静态检查和前端构建通过。

边界：本次没有重新完成真实平台批量下载或另一台实体电脑验收。视觉相似不是重复内容的绝对证明，音轨差异不参与匹配；裁剪、镜像、剪辑、静态及很短的视频仍可能漏检。后台低优先级和空闲调度减少对下载的影响，不承诺所有电脑完全零资源开销。发布包不含用户数据，更新不清除已有视频或登录状态。
